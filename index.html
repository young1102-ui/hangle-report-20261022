1~5번은 필수, 6~10번은 시간이 남으면 연습합니다.
수업 순서 : ① 메모 읽기 → ② 프롬프트 복사 → ③ AI에 붙여넣기 → ④ 결과 확인 → ⑤ 변화 포인트 찾기
※ 브라우저가 자동 복사를 막으면 선택창이 열립니다. 그때 Ctrl+C를 누르면 됩니다.

✨ Alt + C 모양 복사 사용법

  1. 모양을 가져올 글자 바로 뒤에 커서를 놓고 Alt + C
  2. 필요한 경우 글자 모양 / 문단 모양을 선택해 복사
  3. 모양을 바꿀 글자를 블록으로 선택
  4. 다시 Alt + C → 복사한 모양이 적용됨
💡 표 안에서도 사용할 수 있어 보고서의 글꼴·정렬·문단 모양을 맞출 때 특히 편리합니다.
Ctrl + F · 찾기 — 학교명·작물명 빠르게 찾기
Ctrl + H · 찾아 바꾸기 — 반복된 표현 한꺼번에 수정
Alt + L · 글자 모양 — 글꼴·크기·굵기 수정
Alt + T · 문단 모양 — 정렬·들여쓰기·줄 간격 수정
Ctrl + A · 전체 선택 — 필요할 때만
Delete / Backspace · 불필요한 글자 삭제
